# Frontend Scope Guardrail

You may ONLY read and modify files inside the `frontend/` directory of this
repository. Never read, open, edit, create, or delete any file under
`backend/`, `ml/`, `datasets/`, `models/`, `notebooks/`, `tests/`, `docs/`,
or any root-level file (README.md, .gitignore, etc.).

If a task seems to require a change outside `frontend/`, stop and explain
why instead of making the change.
