# SIGMA Datasets Directory

This directory is designated for storing RF recordings and dataset files used for model training and pipeline validation.

## Subdirectories
* `raw/`: Raw `.IQ` and `.wav` RF recordings.
* `synthetic/`: Synthetically generated signals with controlled noise, channel effects, and modulation schemes.
* `processed/`: Preprocessed, segmented, or downsampled datasets ready for feature extraction or neural network ingestion.
